# 🏨 Travel Agent — MCP Toolbox + Google ADK

An AI-powered hotel search agent built with Google ADK and MCP Toolbox for Databases.

🔗 **Live Demo:** https://hotels-service-726281867698.us-central1.run.app/dev-ui/

## Features
- 🔍 Search hotels by city/location
- 🏷️ Search hotels by name
- 💰 Results sorted by price tier
- 🤖 Powered by Gemini 2.5 Flash

## Tech Stack
- Google Agent Development Kit (ADK)
- MCP Toolbox for Databases
- Cloud SQL PostgreSQL
- Google Cloud Run
- Gemini 2.5 Flash (Vertex AI)

## Sample Queries
- "Find hotels in New York"
- "Search for Marriott hotels"
- "Show luxury hotels in Chicago"
- "What hotels are in Miami?"
